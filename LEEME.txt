             DIAGSOFT - SISTEMA DE VENTAS E INVENTARIO

¡Gracias por elegir DiagSoft para su negocio!

CONTENIDO DE ESTE PAQUETE:
--------------------------
- DiagSoft_Setup.exe    : Instalador del sistema
- LEEME.txt             : Este archivo de información
- ventas.db             : Base de datos con datos de ejemplo (opcional)

REQUISITOS DEL SISTEMA:
----------------------
- Sistema operativo: Windows 10/11 (64 bits)
- Procesador: 1.6 GHz o superior
- Memoria RAM: Mínimo 4 GB (recomendado 8 GB)
- Espacio en disco: 500 MB libres
- Resolución de pantalla: 1366 x 768 o superior

INSTALACIÓN:
-----------
1. Ejecute el archivo "DiagSoft_Setup.exe" como administrador
2. Siga las instrucciones del asistente de instalación
3. Al finalizar, se creará un acceso directo en el escritorio

PRIMER INICIO:
-------------
Al iniciar DiagSoft por primera vez, se le solicitará:
- Usuario: admin
- Contraseña: admin123
Se recomienda cambiar esta contraseña inmediatamente después del primer inicio.

FUNCIONALIDADES PRINCIPALES:

- Gestión completa de inventario
- Control de ventas y facturación
- Administración de clientes y proveedores
- Informes y estadísticas
- Exportación de datos a Excel
